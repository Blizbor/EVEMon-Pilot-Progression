# EvE Pilot Progression

EVEMon progression certificates for practical skill-gap auditing — useful both for a new pilot and for a 50M+ SP veteran with uneven support skills.  
Certyfikaty progresji EVEMon do praktycznego audytu luk — zarówno dla nowego pilota, jak i weterana 50M+ SP z nierównymi supportami.

**EvE Pilot Progression** is the diagnostic layer: it shows *where the pilot is now*. Use **EvE Modular Skillplans** to decide *what to train next*, and **EVEMon Certificates Enhanced** when you want more detail for weapon, drone and tank competence.  
**EvE Pilot Progression** jest warstwą diagnostyczną: pokazuje *gdzie pilot jest teraz*. **EvE Modular Skillplans** odpowiada na pytanie *co trenować dalej*, a **EVEMon Certificates Enhanced** daje większą rozdzielczość dla broni, dronów i tanku.
