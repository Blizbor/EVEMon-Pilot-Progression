# Szybki start

1. Zainstaluj EVEMon z https://github.com/mgoeppner/evemon/releases.
2. Uruchom go raz i **zainstaluj wszystkie aktualizacje datafiles/SDE**, które pokaże EVEMon.
3. Zamknij EVEMon.
4. Pobierz ZIP z Releases: https://github.com/Blizbor/EVEMon-Pilot-Progression/releases
5. Rozpakuj i uruchom `Install-EVEMon-Pilot-Progression.ps1`.
6. Otwórz Certificate Browser → EVEMon Pilot Progression.

Jeżeli później EVEMon zaktualizuje pliki danych, uruchom instalator projektu ponownie.
