# FAQ

## Does this change my character skills?
No. It modifies a local EVEMon certificate datafile.

## Does it patch `eve-skills`?
No. If a required skill is missing, the installer stops and asks you to update EVEMon datafiles.

## What after an EVEMon datafile update?
Run the installer again.

## Where do I report a problem?
https://github.com/Blizbor/EVEMon-Pilot-Progression/issues
