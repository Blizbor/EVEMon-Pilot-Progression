# Audyt weterana / 50M+ SP

Duży total SP potrafi ukryć luki: support III przy hull V, stara specialization I, zaniedbane application, drony lub scouting. Pilot Progression ma właśnie takie nierówności uwidocznić. Traktuj niski poziom jako pytanie: „czy ten obszar jest mi potrzebny?”, a nie jako nakaz trenowania wszystkiego.
