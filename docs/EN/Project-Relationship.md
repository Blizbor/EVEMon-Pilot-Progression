# Project relationship

1. **EvE Modular Skillplans** — https://github.com/Blizbor/EvE-Modular-Skillplans — plans training for roles and ships.
2. **EVEMon Pilot Progression** — this repository — provides a broad EVEMon competence dashboard.
3. **EVEMon Certificates Enhanced** — https://github.com/Blizbor/EVEMon-Certificates-Enhanced — adds higher resolution to default weapon, drone and tank certificates.

Pilot Progression and Certificates Enhanced can coexist and can be installed in either order **after** EVEMon datafiles have been updated.
