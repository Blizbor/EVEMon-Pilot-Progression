# Quick start

1. Install EVEMon from https://github.com/mgoeppner/evemon/releases.
2. Start it once and **install every datafile/SDE update** offered by EVEMon.
3. Close EVEMon.
4. Download the ZIP from Releases: https://github.com/Blizbor/EvE-Pilot-Progression/releases
5. Extract it and run `Install-EvE-Pilot-Progression.ps1`.
6. Open Certificate Browser → EvE Pilot Progression.

If EVEMon later updates its datafiles, run the project installer again.
