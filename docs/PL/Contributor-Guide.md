# Zasady dla kontrybutorów

Pełne obowiązujące zasady znajdują się w dokumencie [Zasady tworzenia treści](../CONTENT-GUIDELINES.md).

Najpierw nazwij zwykłym językiem, co oznacza poziom kompetencji. Dopiero potem dobieraj skille.

- BASIC powinien możliwie tanio otwierać możliwość lub obszar gry.
- Wyższy poziom musi mieć widoczny sens praktyczny.
- Nie dodawaj V tylko dlatego, że istnieje.
- Skill ma uzasadniać koszt przez unlock, wymóg T2/hulla/modułu, realną poprawę fita albo standard roli.
- Weryfikuj aktualne nazwy skilli i wymagania w bieżących danych EVE.
- Zmiana, która pochodzi z Modular Skillplans, powinna wskazywać odpowiedni plan/kompetencję.

Problemy i propozycje omawiamy przez GitHub Issues.
