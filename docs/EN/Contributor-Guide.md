# Contributor guide

The complete binding rules are in [Content guidelines](../CONTENT-GUIDELINES.md).

First describe in plain language what a competence level means. Only then choose skills.

- BASIC should unlock a capability or gameplay area with a low sensible SP cost.
- A higher grade must have a visible practical reason.
- Do not add V merely because V exists.
- A skill should justify its cost through an unlock, a T2/hull/module gate, measurable fit improvement, or a role standard.
- Verify current skill names and prerequisites against current EVE data.
- Changes derived from Modular Skillplans should point back to the matching competency.

Use GitHub Issues for design discussion and bug reports.
